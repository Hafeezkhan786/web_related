Add a Project

  1. Sign in to your Clarity account.

  2. Select 'New project' to start adding a project.

  1. Enter the Name and Website details. Select Add new project once done.

Install tracking code

  1. Select a project and go to Settings → Setup

  1. Choose get Tracking Code

  1. Get tracking code

  1. Copy tracking code to Setting → General Setting → Integrations → Microsoft Clarity.

  1. Review your recording videos on https://clarity.microsoft.com/projects
